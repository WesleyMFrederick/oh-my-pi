## 1. Open-memory replay

Script `/tmp/transcript-bloat/open-rss.ts`, run as `/usr/bin/time -l bun /tmp/transcript-bloat/open-rss.ts <file>` with cwd = main checkout:

```ts
// Throwaway repro: open one session file through the real SessionManager and report memory.
import { SessionManager } from "/Users/wesleyfrederick/Documents/ObsidianVault/0_SoftwareDevelopment/oh-my-pi/packages/coding-agent/src/session/session-manager.ts";

const file = process.argv[2];
Bun.gc(true);
const before = process.memoryUsage();
const t0 = performance.now();
const sm = await SessionManager.open(file, undefined, undefined, { suppressBreadcrumb: true });
const openMs = performance.now() - t0;
Bun.gc(true);
const after = process.memoryUsage();
const entries = sm.getEntries();
let modelCall = 0;
for (const e of entries) if (e.type === "custom" && e.customType === "omp:model-call") modelCall++;
const t1 = performance.now();
const ctx = sm.buildSessionContext();
const ctxMs = performance.now() - t1;
console.log(JSON.stringify({ file, sizeBytes: Bun.file(file).size, entries: entries.length,
  modelCallEntries: modelCall, contextMessages: ctx.messages.length, openMs: Math.round(openMs),
  buildContextMs: Math.round(ctxMs), rssBeforeMB: Math.round(before.rss / 1e6),
  rssAfterMB: Math.round(after.rss / 1e6), heapUsedAfterMB: Math.round(after.heapUsed / 1e6),
  maxRSSRaw: process.resourceUsage().maxRSS }));
await sm.close();
process.exit(0);
```

Inputs (copies, originals untouched):
- `A171-full` = copy of the 171,354,770-byte session `01a17968` (pull-based-main-sync).
- `B545-full` = copy of the 545,281,269-byte session `01a184a8` (hardy-crocodile; the session Paseo failed to load, see section 4).
- `*-slim` = same file with every `omp:model-call` entry kept (same id, parent, timestamp) but its `data` cut to `{version, requestId, model, phase}`. This is the stand-in for "bodies stored elsewhere, small reference left behind".
- `B545-delta` = same file with each request/payload record replaced by: a hash reference to the system prompt + tools (stored once per distinct value), the length and hash of the message prefix shared with the previous record of the same phase, and only the messages after that prefix. Responses kept whole. Built by the script in section 2.
